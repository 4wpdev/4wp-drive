# 4WP Drive 1.6.0

**Published:** 2026-09-17  
**WordPress.org:** https://wordpress.org/plugins/4wp-drive/

Incoming is faster to browse, Google Docs tables stay tables, and package images can be previewed without importing.

### Incoming tree

The queue no longer loads the entire Drive tree at once. Folders open one level at a time. Nested folders stay closed until you expand them.

### Google Docs

Classic tables (Risk Zone / White–Red style) import as Gutenberg tables. Site fonts apply unless you keep document fonts.

### Images

Click a jpg/png in the tree to preview it in the workspace. Import stays off. Open-outside still goes to Drive or GitHub.

### Export errors

The red **Export errors** chip is a Google HTML export failure during Sync, not a WordPress import crash. Click it for the file names.
