# 4WP Drive 1.7.0

**Published:** 2026-09-20  
**WordPress.org:** https://wordpress.org/plugins/4wp-drive/

Import Google Docs and Markdown from Drive or GitHub into WordPress drafts—or update existing posts from Incoming.

## Version 1.7.0

Patterns are a real dashboard. You can drop a package image into the article. Family plugins (FAQ and SEO Helper TechArticle) show up even before they are active.

### Images in the post

Drag a jpg/png from the Incoming tree onto the preview, or click the file, pick left / center / right, then click a paragraph. Drive writes `[image:file.png left]`.

### Patterns

**Core Block** is always imported. **Integrations Plugins** lists 4WP FAQ and 4WP SEO Helper from Drive’s family catalog (install or activate from the card). **Custom Blocks** comes later. Overview shows the live front-matter template.

### Compatibility

- **4WP FAQ** — FAQ heading + questions become a `forwp/faq` accordion.
- **4WP SEO Helper** — TechArticle Goal, Context, Steps, Common mistakes wrap as their Gutenberg blocks.

Wrap a section by hand in Incoming (pin + click), or match Heading 2 titles in Patterns.

### Analytics

Every successful import is listed — drafts and published. Restore is no longer on this screen.
