# 4WP Drive 1.1.0

**Published:** 2026-08-18  
**WordPress.org:** https://wordpress.org/plugins/4wp-drive/

## Summary

Update existing WordPress posts and pages from Google Drive — without creating duplicate drafts.

## Highlights

- **Update existing post** — In Inbox preview, choose a target post or page; content, categories, SEO meta, and featured image sync from Drive.
- **Create new draft** — Same as before when you want a fresh post.
- **Preview & import** — One clear path from the inbox card; pick new vs update before you confirm.
- **Open in Drive** — Settings show direct links to root, incoming, published, and failed folders.
- Inbox admin UI fixes (theme CSS scoped to preview so wp-admin sidebar stays intact).

## Short post (social / Google)

4WP Drive 1.1.0: refresh live posts from Google Docs in Drive. Preview in Inbox, update an existing page or create a new draft — no copy-paste. https://4wp.dev/plugin/4wp-drive/

## Longer post (blog / newsletter)

Editorial teams already use 4WP Drive to move Google Docs from an `incoming/` folder into WordPress drafts. Version 1.1.0 adds **update mode**: open Preview & import, select **Update existing post**, pick the target, and import replaces content while keeping slug and status.

Settings now include **Open in Drive** links for your workflow folders. Install or update from WordPress.org, connect Drive under **4WP Drive → Storage sources**, and sync from **Inbox**.
