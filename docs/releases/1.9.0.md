# 4WP Drive 1.9.0

4WP Drive imports Google Docs and Markdown from Drive or GitHub into WordPress drafts.

## Version 1.9.0

AI agents can work with the Incoming queue. Through the WordPress Abilities API (WordPress 6.9+) and 4WP MCP Connector, Claude sees which sources are connected and what waits in Incoming, previews a document, imports it into a new draft or updates an existing post (the old version is kept as a revision), and shows a calendar of materials by date. Same permissions as the Incoming screen; nothing is published automatically.
