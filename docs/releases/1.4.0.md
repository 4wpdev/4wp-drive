# 4WP Drive 1.4.0

**Published:** 2026-09-03  
**WordPress.org:** https://wordpress.org/plugins/4wp-drive/

## Summary

Editorial Inbox redesign — status, storage source tabs, document queue, and a side workspace for preview/import. Google Drive remains the live connector; GitHub and other sources stay on the roadmap.

## Highlights

### For editors

- **Queue + workspace** — select a document on the left; preview, language (Polylang), create/update, and reject on the right.
- **Status bar** — connection, last sync, ready count, Open folder, Sync.
- **Source tabs** — Google Drive (live) with clear Soon tabs for GitHub, OneDrive, and Dropbox.

### For site owners

- Faster review on laptop-sized screens (narrower queue, more room for preview).
- Tested up to **WordPress 7.1**.

## Longer post (blog / newsletter)

**4WP Drive** still connects Google Docs in Drive to WordPress drafts and updates. Version **1.4.0** focuses on the admin **Inbox**: one chrome block with connection and sync status, tabs for storage sources (Google Drive live today), a compact document queue, and a workspace beside it for Preview, Import, and Reject — so editors stop scrolling a sparse list to find the action.

Block template mapping (4WP FAQ / Core Accordion) from **1.3.0** and Polylang import from **1.2.0** remain unchanged.
