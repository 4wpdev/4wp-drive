# 4WP Drive 1.8.0

4WP Drive imports Google Docs and Markdown from Drive or GitHub into WordPress drafts.

## Version 1.8.0

Reject moves only the rejected document to `failed`, not the whole package folder. A leftover package file can be queued again and opened from Incoming.
