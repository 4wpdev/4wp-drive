# 4WP Drive 1.2.0

**Published:** 2026-06-29
**WordPress.org:** https://wordpress.org/plugins/4wp-drive/

## Summary

Multilingual editorial import for Polylang — pick the content language in the Inbox; create and update posts in the correct language without Drive subfolders.

## Highlights

### For editors

- **Content language in Inbox** — when the site has more than one language (Polylang), choose **Content language** before import. No default selection; the admin must pick explicitly.
- **Create in the right language** — new drafts get the selected Polylang language after import.
- **Update in one language** — **Update existing post** lists and validates targets **only in the selected language** (slug/title suggestions respect the filter too).
- **No Drive language folders** — language is not inferred from Drive paths; it is an editorial choice at import time.

### For site owners / admins

- **Settings → Multilingual integration** — registry cards for **Polylang** (live), **WPML** (planned), and **Single language** fallback, with status badges: Active, Inactive, Not installed, Planned.
- **Provider detection** — distinguishes Polylang **installed but inactive** vs **not installed**; WPML shows **Planned** (installed on site is noted, but import does not use WPML yet).
- **Documentation tab** — **Multilingual import** section explains Polylang workflow and WPML roadmap.

### For developers

- Pluggable **`Language_Provider_Interface`** with **`Language_Provider_Registry`** and filter `forwp_drive_language_providers`.
- **`Import_Language_Resolver`** — validates language on REST import; returns `400` when required language is missing.
- **`Import_Target_Resolver`** — optional `$lang` on suggest/resolve; REST `lang` on `GET /import-targets`, `language` on `POST /import/import`.
- REST **`multilingual`** payload on inbox, document preview, import targets, and settings.
- **`Wpml_Provider`** class retained in codebase; **not registered for import** until a future release (Settings shows WPML as **Planned**).

## Longer post (blog / newsletter)

Multilingual editorial teams can keep drafting in Google Drive and importing through **4WP Drive** without guessing which WordPress language a document belongs to. Version **1.2.0** adds **Polylang** support: open **Inbox → Preview & import**, select **Content language**, then create a draft or update an existing post. When you update, the target picker shows only posts in that language.

Language is chosen **manually at import** — there is no default when multiple languages exist, and we do not use language subfolders in Drive. **Settings → Multilingual integration** shows which provider is active (Polylang today), that **WPML is planned**, and how import behaves on your site.

Install or update from WordPress.org, ensure Polylang is active, sync from **Inbox**, and import as usual.
